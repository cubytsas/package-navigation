# Changelog

All notable changes to `@cubyt/navigation` are documented here.

## [1.0.0] - 2026-09-27

Initial public release.

### Added

- Browser SPA navigation helper using the History API for internal routes and full-page navigation for other destinations.
- Query-string construction helper.
- JavaScript redirect helpers and safe same-origin return-path validation to help prevent open redirects.
- TypeScript declarations for the public API.
- Explicit package exports, a minimal npm file allowlist, and no runtime dependencies.
- MIT license.
